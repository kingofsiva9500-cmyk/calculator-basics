# Responsive Calculator

A simple and responsive calculator built using **HTML, CSS, and JavaScript**.

## 📌 About

This project is a basic calculator designed to perform common arithmetic operations. It has a clean and responsive user interface that works on desktop, tablet, and mobile devices.

## 🚀 Features

* Addition
* Subtraction
* Multiplication
* Division
* Percentage calculation
* Clear button
* Delete button
* Decimal numbers
* Responsive design
* Simple and user-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript


## 💻 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Use the calculator to perform calculations.

## 🧮 Operations

The calculator supports:

```text
Addition       → +
Subtraction    → -
Multiplication → ×
Division       → ÷
Percentage     → %
Decimal        → .
```

## 📱 Responsive Design

The calculator is designed to adjust its size and layout according to different screen sizes, including:

* Desktop
* Tablet
* Mobile
